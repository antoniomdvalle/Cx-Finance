# Cx Finance

## Learn Finance. One Lesson at a Time.

Cx Finance is a **gamified financial education platform** inspired by language learning applications such as Duolingo.

Instead of only tracking expenses or displaying financial reports, Cx helps users **learn personal finance through interactive lessons, quizzes, and progression**, making financial literacy accessible, engaging, and rewarding.

The platform combines modern web technologies with educational principles to create an intuitive learning experience.

---

# About the Project

Financial education is often difficult to access or overly technical.

Cx Finance aims to simplify this process by transforming financial concepts into small learning modules where users can:

- Learn through interactive lessons
- Complete quizzes
- Track learning progress
- Build financial knowledge gradually
- Stay motivated through a great experience
